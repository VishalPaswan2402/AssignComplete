# 📝 Text Formatter Website

A simple **Text Formatter** web application built using **HTML, CSS, and JavaScript**, allowing users to format text and download it as a **PDF document**.

## 🚀 Features

✅ **Text Formatting**: Change text style (bold, italic, underline, strikethrough, etc.).  
✅ **Font Customization**: Adjust font size, style, and color.  
✅ **Alignment Options**: Left, center, and right text alignment.  
✅ **Bullet Points & Numbering**: Add lists for better organization.  
✅ **Download as PDF**: Export formatted text into a **PDF document**.  
✅ **User-Friendly Interface**: Simple and interactive UI for easy formatting.  
✅ **Responsive Design**: Works on desktop and mobile devices.
